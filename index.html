How to Install in Google Chrome / Brave / Edge

Follow these steps to load your custom extension into your browser in Developer Mode.

Step 1

Download Code Files

Go to the Extension Files tab, copy each file or click Download Extension Bundle to save all files into a local folder on your computer (e.g., /ClearCacheExtension).

Step 2

Enable Developer Mode

Open Chrome and navigate to chrome://extensions in your URL bar. Toggle on Developer mode in the top-right corner.

Step 3

Load Unpacked

Click the Load unpacked button in Chrome and select the folder containing your downloaded extension files. The extension will appear instantly in your toolbar!

Required Permissions Explained:
  • browsingData: Allows calling chrome.browsingData.remove() to clear cache, cookies, and history.
  • storage: Saves user preferences and domain whitelist securely.
  • alarms: Handles periodic automated cache cleanup schedules.
